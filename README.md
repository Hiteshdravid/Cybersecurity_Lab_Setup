# Cybersecurity_lab_Setup
Kali Linux cybersecurity lab setup for learning Linux fundamentals, ethical hacking, and penetration testing.


## Screenshots

The `Screenshots` folder contains the complete visual documentation of the Kali Linux installation and lab setup process. It includes screenshots captured during each important step, from starting the installation to completing the initial configuration.

### Kali Linux Installation

Kali Linux was installed to create a controlled environment for cybersecurity and ethical hacking practice. The installation process included the following steps:

1. **Booting Kali Linux** – Kali Linux was started using the selected installation method.
2. **Installation Mode** – The appropriate graphical or text-based installation option was selected.
3. **Language and Region** – The required language, location, and keyboard layout were configured.
4. **Network Configuration** – Network settings were configured during the installation process.
5. **User Account Creation** – A username and password were created for accessing the Kali Linux system.
6. **Disk Configuration** – The required disk/virtual disk was selected and configured for the installation.
7. **Software Installation** – The required Kali Linux components and packages were installed.
8. **Bootloader Installation** – The bootloader was configured to allow Kali Linux to start correctly.
9. **Installation Completion** – After the installation was completed, the system was restarted and Kali Linux was successfully booted.
10. **Initial Setup** – The desktop environment and basic system settings were checked after logging in.

The screenshots in this folder provide step-by-step visual evidence of the installation and configuration process.

### Purpose of the Installation

The main purpose of installing Kali Linux is to provide a dedicated environment for learning and practicing:

- Linux fundamentals
- Network security
- Cybersecurity concepts
- Ethical hacking
- Vulnerability assessment
- Penetration testing
- Security tools and utilities

All security testing performed using this environment should be conducted only on systems for which proper authorization has been obtained.
